# TabNav

`<TabNav />` adapts route-backed and state-backed items to `Hds::Tabs`.

Each item in the list should be a hash of `label`, `route` and `selected`.

- `label`: The text to show
- `route`: an Ember route name. Omit this for state-backed tabs using one of the event handlers.
- `selected`: whether the item is in the selected state or not, probably
  of the state to transition to.

There are two similar event handlers, `@onclick` and `@onTabClicked`.

When using `@onclick`, the `item.label` is passed to the handler. When using
`@onTabClick` the entire 'item' is passed instead, therefore you can add
arbitrary properties to the 'item' to be used in the handler.


```hbs
<figure>
 <figcaption>A TabNav with a conditional button using `compact` which removes empty values from arrays</figcaption>
<TabNav @items={{
 compact
     (array
         (hash label="Health Checks" route="docs.health-checks" selected=true)
         (hash label="Service Instances" route="docs.service-instances" selected=(is-href "docs.service-instances"))
(if false (hash label="Don't show me" route="docs.hidden" selected=false) '')
         (hash label="Lock Sessions" route="docs.lock-sessions" selected=false)
         (hash label="Metadata" route="docs.metadata" selected=false)
     )
}}/>
</figure>
```

A TabNav with using a `StateMachine.dispatch`

```hbs
<figure>
  <figcaption>A TabNav with using a StateMachine.dispatch</figcaption>
  <TabNav @items={{
    compact
      (array
        (hash
          label="1"
          selected=(state-matches fsm.state 'one')
          state="ONE"
        )
        (hash
          label="2"
          selected=(state-matches fsm.state 'two')
          state="TWO"
        )
      )
    }}
    @onTabClicked={{pick 'state' fsm.dispatch}}
  />
</figure>
```
