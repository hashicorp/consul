```release-note:breaking-change
sdk: Replaced the `iptables` package with a new `nftables` package for transparent proxy traffic redirection. Traffic redirection now requires the `nft` binary and Linux kernel `nf_tables` support (kernel 3.18+); there is no automatic fallback to `iptables`/`ip6tables`. Hosts where the `nf_tables` kernel module is unavailable or disabled will fail to set up transparent proxy redirection.

cli: Migrated `consul connect redirect-traffic` command from `iptables`/`ip6tables` to `nftables` (`nft`). The command now uses the `sdk/nftables` package which applies rules atomically using the `inet` address family, covering both IPv4 and IPv6 in a single pass.
```
